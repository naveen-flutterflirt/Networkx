# Learning Video AI Frontend Merge Notes

Added a new admin tab directly into:

`dist/js/views/adminDashboard.js`

## New admin tab

`Learning Video AI`

## Backend API path used by frontend

`https://api.itlearn360.com/admin/learning-video/*`

## Features in the admin tab

- Create learning problem
- Add seed topics and search queries
- Select a problem
- Paste manual YouTube seed URLs/IDs
- Start/stop worker
- Queue scan now
- Replan queries
- View worker status
- View generated queries
- View collected video matches
- View topic clusters
- View latest LLM analysis
